# 🌤️ Weatherly - Weather App

A clean and responsive **Weather Dashboard** built with **HTML, CSS & JavaScript**, powered by the **OpenWeather API**.

---

## ✨ Features

- 🌡️ Current temperature & weather condition
- 💧 Humidity & 💨 wind information
- 🌧️ Precipitation probability
- 🌫️ Air quality
- 🕐 Current date & time
- 📅 Hourly weather forecast
- 📆 5-day weather forecast
- 🔍 Search weather by city
- 📱 Responsive design

---

## 🛠️ Tech Stack

**HTML5 • CSS3 • JavaScript • OpenWeather API**
